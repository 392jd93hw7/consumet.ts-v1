Anime discovery and playback metadata endpoints powered by the Hianime provider.

API service deployed

Available endpoints

  • GET /api/health — service status
  • GET /api/search?q=one-piece — search anime
  • GET /api/info?id=anime-id — anime details
  • GET /api/episodes?id=anime-id — episode list
  • GET /api/servers?id=episode-id&subOrDub=sub — available servers
  • GET /api/watch?id=episode-id&server=vidcloud&subOrDub=sub — video sources

All endpoints return JSON. Send OPTIONS requests for CORS preflight.

Preview API · Provider availability and playback depend on the upstream source.
